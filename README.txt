HOW TO USE
1) Open index.html
2) Click the gift 🎁
3) The message appears, then screen fades to black, then the album appears.

CAPTIONS
- Captions are plain HTML in index.html under each image:
  <figcaption class="caption"> ... </figcaption>

PHOTOS
- Replace assets/photo-1.svg ... photo-4.svg with your own images (jpg/png/webp).
- If you replace with jpg/png, update the <img src="..."> paths in index.html.

SONG
- Put your song file at: assets/song.mp3
- Or change the <source src="assets/song.mp3"> in index.html
